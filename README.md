# Frater Bier

Dit is de repository voor Frater. Deze website is bedoeld om klanten te informeren over nieuwe bieren en waar deze te koop zijn. Daarnaast is het voor zakelijke klanten mogelijk om bestellingen te plaatsen.

---

De reden van dit project is dat ik graag mijn vaardigheden wil toepassen voor een commerciele opdracht. Daarnaast wil ik beter worden in het schijven van een thema in WordPress. Daarnaast zit er de uitdaging in om de website naast Nederlands, ook beschikbaar te maken in het Deens en Engels.

---

## Pagina's

* Home
* Ons verhaal
* Waar te koop?
* Contact

---

## Vereisten

Dit thema is met HTML/CSS, JavaScript en PHP geschreven voor WordPress. Om het thema werkend te maken, is een installatie van WordPress nodig.

## Randvoorwaarden

Bij de ontwikkeling van de website wordt rekening gehouden met de AVG-wetgeving.

* **Gegevensverwerking:** Formuliergegevens (zoals bestellingen of contactaanvragen) worden alleen gebruikt voor het afhandelen van de betreffende transactie of vraag.
* **Geen Onnodige Opslag:** Er worden geen privacygevoelige gegevens opgeslagen in lokale sessies of ongebeveiligde bestanden.
* **Cookies:** De website gebruikt alleen functionele cookies. Er worden geen tracking- of marketingcookies geplaatst zonder expliciete toestemming van de bezoeker.
